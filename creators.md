## Read this before the demo

- **Follower counts are snapshots** from the source listed for each creator, not live numbers. Sources range from 2024 to Oct 2026, so refresh the counts for the creators you plan to show.
- **Contact details are blank on purpose.** None of the sources publish creator or manager emails (most directories put them behind a sign-up). Fill them in from each creator's Instagram bio or YouTube About page, and only use business emails they list publicly.
- **Engagement rate** is shown only where the source reported one. Some directory figures are unusually high and worth double-checking.
- **Niche tags** follow the category the source ranked them under. A few creators sit in more than one niche.
- `creators.json` holds the same list in the format the Creator Finder page reads, so you can drop it into the "Your roster" loader as-is.
